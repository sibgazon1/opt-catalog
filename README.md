# Локальная копия https://gazony.ru/opt/

Снимок оптового каталога для правок. Живой сайт не трогает.

## Запуск

```powershell
cd "C:\Content cursor\apps\opt-catalog"
py -3 server.py
```

Открыть: http://127.0.0.1:8765/

Важно: правь только локальный адрес `127.0.0.1:8765`, не `gazony.ru/opt/`. Ссылки на разделы и карточки ведут на локальные страницы.

## Страницы

| Путь | Что это |
|------|---------|
| `/` | главная витрина (hero + каталог) |
| `/derevya/`, `/kustarniki/`, `/hvoynye/` | разделы |
| `/derevya/<slug>/` и т.п. | карточки товаров |

## Что править

| Файл | Зачем |
|------|--------|
| `index.html` | главная: тексты, hero, карточки |
| `derevya/`, `kustarniki/`, `hvoynye/` | разделы и товары |
| `static/css/styles.css` | общие стили (шапка, hero, фото) |
| `static/js/opt.js` | корзина и скидки (две лестницы: деревья / остальное) |
| `media/wholesale/gallery/...` | фото |

Конфиг скидок: `<script id="opt-discount-config">`.
- `tiers` + `entry_percent` = кустарники и хвойные (20 / 25 / 30 / 35 / инд.)
- `by_section.derevya` = деревья (5 / 10 / 15 / 20 / инд.)

Корзина считает скидку отдельно по группам (объём деревьев не смешивается с остальным).

## Ограничения

- Отправка заказа пишет в `data/orders.json`, на прод API не ходит.
- Обновить снимок с прода: `py -3 state/opt-refresh/mirror_fresh.py`, потом `py -3 state/opt-refresh/force_assets.py`.
